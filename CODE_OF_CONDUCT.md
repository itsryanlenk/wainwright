# Code of Conduct

## Our standard

This project adopts the **Contributor Covenant, version 2.1**. The full text:

> https://www.contributor-covenant.org/version/2/1/code_of_conduct/

In short: act with respect and good faith, keep the focus on the work, and help make
participation welcoming for people of all backgrounds. Disagreement is expected; treating
people poorly is not.

## Scope

All project spaces (repository, issues, pull requests, discussions) and anyone representing
the project in public.

## Reporting and enforcement

Report unacceptable behavior privately, not in a public thread:

- through the repository's **Security > Report a vulnerability** tab, or
- through the maintainer's GitHub profile: https://github.com/itsryanlenk

Reports are handled as described in the Enforcement and Enforcement Guidelines sections of the
linked Contributor Covenant.
